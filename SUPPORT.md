## Reporting Issues

If you encounter bugs, unexpected behavior, or have feature suggestions, please report them via the [GitHub Issues](https://github.com/VoxDroid/Advanced-Tab-Manager/issues) page. To ensure your issue is addressed efficiently:

1. **Search Existing Issues**: Check if your issue has already been reported to avoid duplicates.
2. **Use the Issue Template**: Select the appropriate template (Bug Report, Feature Request, or General Inquiry) when creating a new issue.
3. **Provide Details**:
   - Describe the issue clearly, including steps to reproduce it.
   - Specify your operating system (Windows, macOS, Linux), Python version, and application version.
   - Include relevant logs from the **Logs Tab** or screenshots if applicable.
4. **Submit the Issue**: Post your issue and monitor it for responses from the maintainers.
