## Reporting a Vulnerability

If you discover a security vulnerability, please report it promptly and responsibly. To report a vulnerability:

1. **Do Not Disclose Publicly**: Avoid sharing details of the vulnerability in public forums, such as GitHub Issues, Discussions, or social media, until it has been addressed.
2. **Submit a Report**:
   - **Preferred Method**: Email the developer at [izeno.contact@gmail.com](mailto:izeno.contact@gmail.com) with the subject line “Security Vulnerability: Advanced Tab Manager Pro”.
   - **Alternative Method**: For non-sensitive issues, use the **Security Report** issue template on the [Issues](https://github.com/VoxDroid/Advanced-Tab-Manager/issues) page, but avoid including sensitive details.
3. **Include Details**:
   - A clear description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact (e.g., data exposure, unauthorized access).
   - Your contact information for follow-up.
4. **Response Process**:
   - You will receive an acknowledgment within 48 hours.
   - The developer will investigate and prioritize the issue.
   - A fix will be developed and released as soon as possible, with credit to the reporter (if desired).
   - You will be notified when the issue is resolved.

## Security Practices

To ensure the security of **Advanced Tab Manager Pro**, the project follows these practices:

- **Dependency Management**: Dependencies (e.g., PyQt6, selenium) are regularly updated to address known vulnerabilities.
- **Process Isolation**: Chrome and ChromeDriver processes are carefully managed to prevent resource leaks or unauthorized access.
- **Error Handling**: Comprehensive error detection and logging minimize the risk of exploitation.
- **Secure Configuration**: Options like proxy settings and custom user agents are validated to prevent misuse.
- **Community Feedback**: Security reports from the community are taken seriously and addressed promptly.

Users are encouraged to:
- Keep their system and dependencies updated.
- Use the latest version of [Google Chrome](https://www.google.com/chrome/).
- Avoid running the application with unnecessary permissions (e.g., as an administrator).
